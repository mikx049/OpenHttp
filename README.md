# OpenHttp

**The Lightweight Local Server**

OpenHttp is a lightweight local server running on Bun. It includes a built-in TUI for managing the server.

OpenHttp currently supports Windows and Linux.

macOS support is planned for OpenHttp 4.0.

## Features

- Lightweight local server
- Built-in TUI
- Server status
- PID-based server detection
- Windows support
- Linux support
- macOS support planned for 4.0
- Powered by Bun

## Requirements

- Bun v1.3.13 or newer
